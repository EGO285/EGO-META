Questions fréquentes

FAQ complète

Comment obtenir un code d'invitation ?

EGO-META est un site sur invitation uniquement. Demande un code à un membre déjà inscrit ou à l'administrateur de ta communauté — il peut en créer autant que nécessaire depuis le panneau d'administration.

Comment se connecter avec Google ou GitHub ?

Sur l'écran de connexion, clique sur « Continuer avec Google » ou « Continuer avec GitHub ». Comme ces fournisseurs ne permettent pas de transmettre un code d'invitation à la création du compte, il te sera demandé d'en saisir un juste après ta première connexion pour activer ton compte.

J'ai oublié mon mot de passe, que faire ?

Sur l'écran de connexion, clique sur « Mot de passe oublié ? », renseigne ton email : un lien de réinitialisation t'est envoyé (pense à vérifier tes spams).

Comment envoyer un message vocal ?

Dans une conversation, appuie sur l'icône micro , autorise l'accès au micro si demandé, parle, puis envoie ou annule ton enregistrement.

Comment transférer un message ?

Survole un message et clique sur l'icône , choisis une ou plusieurs conversations de destination, puis valide.

Comment mettre un message en favori ?

Clique sur l'icône étoile à côté d'un message pour l'ajouter à tes favoris. Retrouve tous tes messages favoris depuis l'icône du menu latéral.

Comment archiver une conversation ?

Clique sur le menu ⋮ d'une conversation dans la liste, puis « Archiver ». Retrouve tes conversations archivées depuis l'icône du menu latéral, où tu peux les désarchiver à tout moment.

Comment créer un sondage ?

Ouvre une conversation, clique sur l'icône dans la barre du haut, puis renseigne ta question et tes options dans le formulaire « Créer un sondage ».

Comment bloquer quelqu'un ?

Depuis le profil d'un membre ou tes paramètres (onglet Confidentialité), tu peux bloquer un utilisateur : il ne pourra plus t'envoyer de message privé.

Comment signaler un message ou un membre ?

Survole un message et clique sur , ou ouvre le profil d'un membre pour le signaler. Le signalement est transmis à l'administrateur du site.

Comment installer EGO-META comme une application ?

Sur la plupart des navigateurs mobiles et de bureau récents, une option « Ajouter à l'écran d'accueil » ou « Installer l'application » apparaît dans le menu du navigateur. Cela crée une icône dédiée, sans passer par un store d'applications.

Pourquoi je ne reçois pas de notifications ?

Vérifie que tu as autorisé les notifications dans Paramètres → Apparence → « Notifications navigateur ». Ces notifications fonctionnent tant que l'onglet EGO-META reste ouvert (même en arrière-plan), mais pas si le site est complètement fermé.

Comment changer de thème ?

Dans Paramètres → Apparence, active ou désactive le thème sombre et choisis ta couleur d'accent parmi les options proposées.

Puis-je passer des appels audio/vidéo ?

Pas encore dans la version actuelle d'EGO-META. C'est une évolution possible à envisager pour une prochaine version.

Quelles données EGO-META stocke-t-il sur moi ?

Uniquement ce qui est nécessaire au fonctionnement du site (profil, messages, fichiers envoyés). Consulte notre politique de confidentialité pour le détail complet.
